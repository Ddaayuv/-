# 🎓 بوت أكاديمية الأمن السيبراني

بوت Telegram باللغة العربية لتصفح المواد والمحاضرات والملفات، مع بحث عربي/إنكليزي وإدارة محتوى من داخل تيليجرام. المشروع مصمم ليعمل كـ **Worker على Railway** أو محلياً.

## الميزات

- قائمة مواد مع محاضرات وملخصات وملفات وأسئلة ومصادر.
- المواد التي تدعم العملي والنظري تعرض خياراً بعد الضغط عليها. المواد الأخرى تدخل إلى محتواها مباشرة.
- إضافة محتوى بالقالب أو بطريقة خطوة بخطوة: مادة ← عملي/نظري ← القسم ← عنوان/وصف أو ملف، ثم معاينة وتأكيد.
- تخزين كل محاضرة داخل المادة والقسم والنوع المحددين في قاعدة البيانات، مع حفظ ملفات تيليجرام باستخدام `file_id`.
- لوحة مطوّر خاصة بـ `OWNER_IDS`: إحصائيات، إذاعة للمستخدمين مع معاينة وتأكيد، ضبط الاشتراك الإجباري، إشعار العضو الجديد، والإعلانات، مع أزرار لإظهار/إخفاء المواد وتبديل دعم العملي/النظري.
- إرسال إشعار للمالك عند تسجيل مستخدم لأول مرة، ويمكن إيقاف الإشعارات من `/adminpanel`.
- اشتراك إجباري في قناة يمكن ضبطها من البوت، مع زر إعادة التحقق.
- سجلات إدارة ونسخ احتياطي يومي يُرسل إلى المالك أو إلى `BACKUP_CHAT_ID`.
- يدعم SQLite، كما يدعم PostgreSQL عبر `DATABASE_URL`.
- تتم إضافة الأعمدة الجديدة إلى قاعدة SQLite الموجودة عند التحديث، مع الاحتفاظ بالمستخدمين والمحاضرات.

## التشغيل محلياً

1. أنشئ بوتاً من [@BotFather](https://t.me/BotFather) وخذ `BOT_TOKEN`.
2. اعرف رقم Telegram الخاص بك، ثم انسخ `.env.example` إلى `.env`.
3. ضع التوكن ورقمك في `BOT_TOKEN` و`OWNER_IDS`.
4. ثبّت المتطلبات وشغّل البوت:

   ```bash
   python -m venv .venv
   # Windows: .venv\Scripts\activate
   # Linux/macOS: source .venv/bin/activate
   pip install -r requirements.txt
   python -m bot.main
   ```

## النشر على Railway

### الخيار A — PostgreSQL (أنسب لاستضافة Railway)

1. ارفع المجلد إلى مستودع GitHub واربطه بخدمة Railway.
2. أضف خدمة PostgreSQL إلى المشروع.
3. في متغيرات خدمة البوت، أضف:
   - `BOT_TOKEN` = توكن البوت.
   - `OWNER_IDS` = رقم Telegram للمطوّر.
   - `DATABASE_URL` = رابط اتصال PostgreSQL من خدمة قاعدة البيانات، مثل مرجع Railway `${{Postgres.DATABASE_URL}}`.
   - `ACADEMY_NAME` = اسم الأكاديمية (اختياري).
4. أمر التشغيل: `python -m bot.main`، أو اترك `railway.json` يحدده.
5. انشر الخدمة. لا حاجة إلى فتح منفذ HTTP لأن البوت يعمل عبر Telegram polling.

### الخيار B — SQLite

أضف Railway Volume واجعل مسار الربط `/app/data`، ثم اضبط المتغير `DB_PATH=/app/data/bot.db`. لا تستخدم SQLite من دون Volume دائم إذا كنت تريد بقاء بياناتك بعد إعادة إنشاء الحاوية.

## إعداد أول مرة

- أضف البوت مشرفاً في قناة الاشتراك حتى يستطيع التحقق من العضوية. وللنشر التلقائي، يحتاج صلاحية نشر الرسائل.
- افتح البوت من حساب المطوّر واكتب `/adminpanel`.
- اختر **إعداد القناة** ثم أرسل، مثلاً: `/setchannel @yourchannel | https://t.me/yourchannel`.
- فعّل الاشتراك الإجباري من اللوحة بعد التأكد من إعداد القناة.
- عدّل طبيعة المواد أو إظهارها/إخفائها مباشرةً من أزرار «إدارة المواد»، أو استخدم `/togglepractical رقم_المادة`.

## استخدام المطوّر والمشرف

- `/adminpanel` — لوحة المطوّر، للمالك المحدد في `OWNER_IDS` فقط.
- `/stats` — إحصائيات (للمالك فقط؛ متوفرة أيضاً داخل لوحة المطوّر).
- `/add` — إضافة محتوى بالقالب أو خطوة بخطوة.
- `/subjects` — عرض المواد وأرقامها وطبيعتها.
- `/addsubject الاسم العربي | English | 📘 | مرادف1,مرادف2 | عملي` — إضافة مادة جديدة مع خيار العملي/النظري. احذف الجزء الأخير إذا لم تكن المادة عملية.
- `/togglesubject رقم` — إظهار/إخفاء مادة.
- `/togglepractical رقم` — تبديل المادة بين عملي/نظري وقسم واحد.
- `/setchannel @channel | https://t.me/channel` — ضبط القناة، للمالك فقط.
- `/broadcast` — بدء إذاعة (للمالك فقط)؛ يمكن أيضاً استخدام زر الإذاعة في لوحة المطوّر.
- `/edit رقم` متبوعاً بأسطر مثل `العنوان:` و`الوصف:` و`الرابط:` — تعديل عنصر.
- `/hide رقم` و`/unhide رقم` و`/delete رقم` و`/undo` — إدارة المحتوى.
- `/addadmin ID` و`/rmadmin ID` و`/admins` — إدارة مشرفي المحتوى، للمالك فقط.

### قالب إضافة المحتوى

```text
المادة: أساسيات Linux
القسم: المحاضرات
النوع: نظري
العنوان: المحاضرة الأولى
الأسبوع: 1
الرابط: https://example.com/lecture
الوصف: مقدمة إلى الطرفية وأوامر لينكس
وسوم: لينكس، طرفية
مهم: نعم
```

كرر سطر `الرابط:` لإضافة روابط متعددة، أو أرفق ملفاً/فيديو/صورة/صوتاً مع نص القالب كتعليق. اختر «عملي» أو «نظري» للمواد التي تدعم النوعين. يتم عرض معاينة قبل النشر.

### طريقة الإذاعة

اضغط «إذاعة رسالة» أو اكتب `/broadcast`، ثم أرسل النص أو الملف، راجع المعاينة واضغط **تأكيد الإرسال**. تُظهر النتيجة عدد الرسائل الناجحة والمحظورة والأخطاء. لا يستطيع البوت مراسلة حساب لم يبدأ محادثة معه سابقاً؛ لذلك الإذاعة تصل إلى المستخدمين الذين سبق أن فتحوا البوت.

## ملاحظات مهمة

- لا ترفع ملف `.env` إلى GitHub؛ يحتوي على أسرار البوت ومعرّف المطوّر.
- إذا لم يعمل الاشتراك الإجباري، تحقق من صحة معرف/رابط القناة ومن أن البوت مشرف فيها. عند تعذّر التحقق لا يسمح البوت للطالب بالمرور بشكل تلقائي.
- قاعدة SQLite القديمة تُرقّى تلقائياً عند التشغيل. احتفظ بنسخة احتياطية قبل أي نشر كبير.
- جلسات الإضافة والإذاعة المؤقتة في الذاكرة؛ إذا أُعيد تشغيل الخدمة قبل التأكيد، ابدأ العملية من جديد. المحاضرات المنشورة تبقى في قاعدة البيانات.
- ملف النسخ الاحتياطي من PostgreSQL هو تصدير JSON مضغوط للجداول؛ احتفظ به خارج Railway أيضاً.

## تحديث الصيانة: الاشتراك والقوائم والاختبارات

- **الاشتراك الإجباري متعدد القنوات:** من لوحة المطوّر افتح «إدارة القنوات». أضف قناة باستخدام `/addchannel @channel | https://t.me/channel`، أو أزلها من اللوحة أو باستخدام `/removechannel @channel`. عند استخدام قناة خاصة، مرّر المعرّف الرقمي مثل `-1001234567890` ورابط الدعوة: `/addchannel -1001234567890 | https://t.me/+invite`. يجب أن يكون البوت مشرفاً في كل قناة حتى يتمكن Telegram من إرجاع عضوية المستخدم بصورة موثوقة.
- **التعامل مع أخطاء التحقق:** إذا تعذّر الاتصال أو لم تسمح صلاحيات البوت بالتحقق، تظهر رسالة إعادة المحاولة ولا يتم اعتبار المستخدم غير مشترك لمجرد وقوع الخطأ.
- **قائمة الدراسة:** في اختيار النظري/العملي يظهر زر المحاضرات فقط. تبقى جداول الملفات والأسئلة وبياناتها ومعالجاتها في المشروع، ولم تُحذف من قاعدة البيانات.
- **إدارة الأزرار:** من لوحة المطوّر افتح «إدارة الأزرار». يمكن إضافة زر من الوظائف المدعومة، تغيير اسمه، إظهاره أو إخفاؤه، تغيير ترتيب عرضه، أو حذف الزر المخصص بعد التأكيد. لا يسمح النظام بربط زر بوظيفة غير معروفة. «استعادة الأزرار الافتراضية» يعيد الأزرار الأساسية ويخفي الأزرار المخصصة بدلاً من حذفها.
- **إنشاء اختبار من نص:** استخدم «🤖 إنشاء اختبار بالذكاء الاصطناعي». أرسل النص بتنسيق السؤال والاختيارات والإجابة الصحيحة، راجع المعاينة ثم أكد الإنشاء. يتم التحليل محلياً بشكل حتمي دون إرسال نص المستخدم إلى مزود خارجي ودون مفتاح API. رغم اسم الزر، هذا الإصدار لا يستدعي نموذجاً لغوياً؛ النص غير المنتظم الذي لا يمكن تحليله بأمان يُرفض مع ذكر الأخطاء بدلاً من تخمين إجابة.
- **طريقة عرض الاختبار:** تُرسل الأسئلة كاستطلاعات Telegram من نوع Quiz مع الإجابة الصحيحة المحددة. تحفظ الاختبارات والمحاولات والإجابات في قاعدة البيانات، ويحسب البوت النتيجة بعد استلام الإجابات. استخدم `/myquizzes` لإعادة محاولة اختبار محفوظ. المحاولات غير المكتملة تبقى محفوظة دون اعتبار الأسئلة التي لم تُجب إجابات خاطئة.

### اختبارات محلية

شغّل اختبارات المحلل من مجلد المشروع:

```bash
pip install -r requirements-dev.txt
python -m pytest -q
```

واختبر أن ملفات المشروع قابلة للتحليل:

```bash
python -m compileall -q bot tests
```

هذه الاختبارات المحلية لا تتصل بـ Telegram. لاختبار الاشتراك الفعلي وإرسال الاستطلاعات، شغّل البوت بإعداداتك الحقيقية بعد أخذ نسخة احتياطية، واستخدم قناة اختبار وحساب مستخدم تجريبي.



### النسخ الاحتياطي بعد التحديث

أصبحت النسخة الاحتياطية JSON تشمل المستخدمين والمواد والأقسام والمحتوى والمرفقات والمشرفين وسجل الإدارة والإعدادات غير السرية والأزرار الديناميكية والاختبارات ومحاولاتها وإجاباتها. تُحجب القيم التي تبدو أسراراً بناءً على اسم مفتاح الإعداد. احتفظ أيضاً بنسخة مستقلة من ملف قاعدة البيانات قبل نشر التحديث؛ ملف JSON مخصص لتصدير البيانات ولا يقوم وحده بإعادة بناء قاعدة البيانات آلياً.

## حماية البيانات (تحديث)

- أُزيل الترحيل الذي كان يحذف نهائياً محتوى «الملفات» و«الأسئلة». لا يوجد الآن أي حذف تلقائي للبيانات عند التشغيل.
- تظهر للمستخدم كل الأقسام التي فيها محتوى منشور (مع عدد العناصر)، فلا يختفي شيء مخزّن في القاعدة.
- نسخة SQLite تُؤخذ تلقائياً قبل كل تشغيل داخل `data/snapshots` (آخر 5 نسخ).
- `/backup` يرسل نسخة JSON كاملة تشمل المرفقات (`file_id`)، و`/restore` يستعيدها بإضافة المفقود فقط دون حذف أو تعديل.
- عند حذف محتوى يُحفظ نصه ومرفقاته كاملة في سجل الإدارة.
- إذا كانت القاعدة فارغة عند التشغيل يرسل البوت تنبيهاً للمالك (علامة أن التخزين غير دائم).
